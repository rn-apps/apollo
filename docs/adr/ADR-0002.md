# ADR-0002 — Rebuilt fresh on kiln: backend ported onto current pykit, frontend rewritten in Angular

**Status:** proposed (2026-11-15) · **Scope:** how the old apollo's code and
contracts carry into this repository

## Decision

This repository was generated by
`kiln new --archetype python-web-app --backend fastapi --frontend angular` on
2026-11-15. It reaches feature parity with the old apollo, which is kept
read-only at `rn_backup/apollo`.

- **Backend: ported, story by story.** Each story reads the old module it
  replaces and moves its domain logic. The generic infrastructure is replaced
  by the current pykit releases: `FastApiApp`, problem rows from the error
  hierarchy, the async SQLite engine and embedded migrations, `ThreadActor`,
  `TaskPool.map_settled`, `PathUtils` and `sse_response`
  ([E1](../specs/epics/E1-backend-foundation/index.md)). apollo keeps no copy
  of what pykit ships.
- **Frontend: rewritten.** The SvelteKit app's screens, routes and behaviour are
  the requirements. Its code is not translated file by file: it is rebuilt on
  ngkit and on apollo's shared domain components ([ADR-0003](ADR-0003.md),
  [ADR-0004](ADR-0004.md)).
- **Contracts are free to change.** The old app never ran against the real
  library, so there is no deployed database and no client to keep compatible.
  The API moves to `/v1` with RFC 9457 problems ([ADR-0020](ADR-0020.md)), and
  `apollo.db` starts from one fresh baseline migration.

## Consequences

- No history moves over. The old Azure DevOps history stays in `rn_backup`.
- A story that ports code names its old source files, and its tests are written
  first against the new contract. Old tests are re-expressed as needed, not
  copied.
- Milestone-named leftovers (`m9.py`, `test_m9.py`, `test_n4.py`) and the
  deprecated `/searches`, `from-search` and `import-playlist` routes are not
  ported.
- A failure that an empty kiln-generated repository also shows is a kiln defect.
  It is fixed in kiln (kiln S16.5.3), not patched here.

## Alternatives considered

- **Port in place on the old repository, as a branch** (the 2026-10-20 R1–R11
  plan). That plan moved the old history from Azure DevOps to GitHub first,
  and kept SvelteKit-era names and the sync database layer. The fresh
  repository, as agentkit was done on 2026-11-14, starts on the kiln standard
  with nothing to unwind.
- **Translate the Svelte components one to one.** The old UI built the same
  concepts several times: three tag-edit surfaces, five track tables and
  eleven hand-written dry-run confirms. A translation would carry those copies
  into Angular.

## Background

The R1–R11 build plan (`rn_backup/apollo/docs/specs/kiln-rebuild-plan.md`,
2026-10-20, revised 2026-10-24) is superseded. The pykit pieces it built
"extraction seams" for have since shipped: pykit F17.1 to F17.5 and F6.2 are
closed.
