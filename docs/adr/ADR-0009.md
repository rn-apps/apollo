# ADR-0009 — Every mutation is dry-run first, audited before it acts, reversible, and pruned only with its backups

**Status:** proposed (2026-11-15) · **Scope:** every operation that changes a
file, the index, a playlist or Music.app

## Decision

- **Dry run first.** Every mutating endpoint accepts `dry_run`. A dry run
  returns the exact plan: each item's before and after, and each path's old
  and new location. The apply call carries what the dry run returned (for
  example the expected mtime), and is refused if the current state no longer
  matches.
- **Audit before acting.** Before each item changes, an audit entry is written
  that records its inverse, with one `batch_id` per user action. A failure on
  one item is recorded and the batch continues.
- **Reversible.** Undo replays a batch newest first, and writes an inverse audit
  entry before each reversal. A replaced or deleted file goes to trash, never
  to unlink, so undo can restore it.
- **Pruned together.** Pruning history (default TTL 90 days, run manually)
  deletes audit batches together with their trash backups, in one transaction.
  "Empty trash" removes only payloads that no audit entry references. Both are
  themselves audited.

## Consequences

- The UI for every mutation is the dry-run flow ([ADR-0004](ADR-0004.md)):
  preview, diff, confirm, apply.
- Trash grows until the user prunes it. Maintenance shows its size.
- An audit entry can never point at a missing backup, and a backup can never
  outlive every entry that references it.

## Influences

- [E1](../specs/epics/E1-backend-foundation/index.md),

## Alternatives considered

- **Audit after acting.** A crash between the act and the audit write leaves a
  change with no record and no inverse.
- **Separate retention for audit and trash.** Either one could then outlive the
  other: an undo with no file to restore, or orphaned backups nobody can find.

## Background

Restates the old principle "mutations are dry-run first, audited and
reversible", from `docs/architecture/principles.md` and `call-flows.md`, and old
apollo ADR-0021 (recorded 2026-08-31; originally I56). ADR-0021's prune and
empty trash were never built in the old app, so they are new work here.
