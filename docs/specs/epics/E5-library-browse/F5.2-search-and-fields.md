Search across the index with the field vocabulary the query box understands.
API: `GET /v1/fields` (field descriptors) and the `query` parameter of
`GET /v1/tracks`. Saved queries stay transient per
[ADR-0015](../../../adr/ADR-0015.md); the deprecated `/searches*` endpoints are
not rebuilt. The search box and its results use the E4 track workspace.
