The Songs page: a paged, sortable list of every track in the library with the
inspector beside it. API: `GET /v1/tracks` (paged, query and sort) and
`GET /v1/tracks/{id}`. It is the E4 track workspace with the library column set
and row actions, with no grid code of its own, and opens the E4 media editor for
the selected track.
