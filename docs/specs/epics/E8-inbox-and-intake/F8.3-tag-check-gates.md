Checking each staged file's tags and path against the library's rules and gating
promotion on the result. API: `GET /v1/inbox/{path}/check`. The same tag check
engine serves the library
([F11.1](../E11-checks-and-relocation/F11.1-track-checks-cache.md)), and one
badge component shows the outcome in the grid and the media editor.
