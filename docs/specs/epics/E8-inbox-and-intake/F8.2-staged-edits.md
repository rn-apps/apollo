Editing tags on staged files before promotion. API: `POST /v1/inbox/edit`,
`POST /v1/inbox/clean-tags`, `POST /v1/inbox/common-tags` and
`POST /v1/inbox/bulk-edit`. Edits run through the same workflows as the library
([E6](../E6-tag-editing/index.md)); the UI is the E4 media editor and bulk edit
panel with the inbox adapter.
