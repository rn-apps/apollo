Reversing a whole batch by applying each entry's inverse in reverse order,
refusing when a file has changed since. API: `POST /v1/audit/batches/{id}/undo`
(preview, then apply as a job). The preview and confirm steps are the E4 dry-run
flow, and the undo is itself audited.
