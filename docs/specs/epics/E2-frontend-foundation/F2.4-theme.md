apollo's dark workstation look, expressed only as values for ngkit's `--rnf-*`
tokens and a few `--apollo-*` layout tokens
([ADR-0003](../../../adr/ADR-0003.md)).

## Design

`apps/web/src/styles/` holds:

- `theme-apollo.css`: sets every `--rnf-*` token from the old palette, verbatim,
  and `color-scheme: dark`, the fonts, and `--apollo-*` tokens for rail and
  sidebar widths, row heights and hero gradient stops.
- `base.css`: apollo's own element defaults (the 820 px row-height rule, reduced
  motion), on tokens only.
- `styles.scss`: imports ng-tailwind's `tokens.css`, `base.css` and
  `tailwind.css`, then `theme-apollo.css` and `base.css`, in that order.

Features use Tailwind utilities for layout, spacing and type, and the semantic
colour utilities of ng-tailwind's bridge. Arbitrary colour values are not
allowed.

## S2.4.1 — Theme file and contract

**State:** Active

**Acceptance:**

- `S2.4.1: no colour literals`: a spec scans `src/app/**/*.{ts,html,scss}` and
  `src/styles/base.css` and finds no hex, `rgb(`, `hsl(` or `text-[#…]`
  literal. Only `theme-apollo.css` contains them.
- `S2.4.1: tokens set`: every `--rnf-*` token that ng-tailwind's `tokens.css`
  declares is also set in `theme-apollo.css`.
- The themed starter page rendered at 1280 px matches the old palette by eye.
  The owner checks this against the old app before moving on to the connected
  home.
