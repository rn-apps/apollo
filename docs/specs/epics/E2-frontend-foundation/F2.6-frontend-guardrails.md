## S2.6.1 — Layer boundaries in ESLint

**State:** New

**Acceptance:**

- `apps/web/eslint.config.mjs` has `no-restricted-imports` blocks, one per
  layer:
    - `core` imports no other app folder;
    - `shell` imports only `core`;
    - `domain` imports only `core`;
    - `features/x` imports `core`, `shell`, `domain` and its own folder.
- A wrong-way import, made on a scratch branch, fails `task lint`, and the
  message names the rule.
