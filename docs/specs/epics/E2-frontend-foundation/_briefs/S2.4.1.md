# S2.4.1 — Theme file and contract

Brief for [S2.4.1](../F2.4-theme.md#s241-theme-file-and-contract), at `40496eb`.

## Goal

Give the starter page Apollo's dark workstation palette by setting ngkit's
`--rnf-*` tokens, and lock the "colours live only in the theme" contract with
two specs.

## Settled

- Colours are ngkit token values plus a few `--apollo-*` layout tokens
  ([ADR-0003](../../../../adr/ADR-0003.md), [F2.4](../F2.4-theme.md#design)).
- The token mapping below is taken verbatim from the old
  `rn_backup/apollo/apps/web/src/app.css`. Tokens the old app had no value for
  repeat ngkit's dark value or default unchanged.
- The owner approved `@types/node` as a root devDependency for the file-scanning
  specs on 2026-11-19.
- Font files are not loaded. The font stacks fall back to `system-ui` and
  `ui-monospace` until a later story adds the fonts.

## Current behaviour

`apps/web/src/styles.scss` imports ng-tailwind's `tokens.css`, `base.css`,
Tailwind and ng-tailwind's `tailwind.css`, under
`@layer theme, base, rnf, components, utilities;`. `apps/web/src/styles/` does
not exist. The page renders with ngkit's default slate and blue palette.

## Tests first

Write both specs in `apps/web/src/app/theme.spec.ts` with `node:fs`, and resolve
paths from `process.cwd()` (the repo root when `task test` runs, so
`apps/web/src/...`). Both fail before the change.

- `S2.4.1: no colour literals`: walk `apps/web/src/app` recursively, collect
  `*.ts`, `*.html` and `*.scss`, add `apps/web/src/styles/base.css`, and skip
  `theme.spec.ts` itself. Assert that no file matches
  `/#[0-9a-fA-F]{3,8}\b|rgba?\(|hsla?\(|-\[#/`. On a failure, report the
  offending file paths. The spec fails before the change because `base.css` is
  missing. Throw a clear error when a listed file does not exist.
- `S2.4.1: tokens set`: read
  `node_modules/@rn-forge/ng-tailwind/assets/tokens.css` and
  `apps/web/src/styles/theme-apollo.css`. Collect declared names with
  `/(--rnf-[a-z0-9-]+)\s*:/g` from each. Assert that the ngkit set is
  non-empty and that every ngkit name is in the theme set.
