`apps/web` (and the root `package.json`) on `@rn-forge/ng` and
`@rn-forge/ng-tailwind` at the current ngkit release, with Tailwind v4,
`@angular/cdk` and `@angular/aria`.

## Design

ngkit ships its libraries as GitHub Release tarballs, all at one version. The
web app pins both of its ngkit libraries to the same release URL. kiln seeds the
`@rn-forge/ng` pin at v0.3.0. kiln S16.5.5 moves it to v0.4.0 for later
repositories, and the root `package.json` is seeded, so this repo edits the pin
to v0.4.0 by hand
([F1.1](../E1-backend-foundation/F1.1-dependencies-and-entry.md#context)).
`@rn-forge/ng-tailwind` is added here, at the same version. `@angular/cdk` and
`@angular/aria` are added as ng-tailwind's peers; if ngkit has not yet declared
them, that is an E3 finding. `ngxtension` is added for `linkedQueryParam`
(F2.5).

Accepting this feature approves these dependencies.
