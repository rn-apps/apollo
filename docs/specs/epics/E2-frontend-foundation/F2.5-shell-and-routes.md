The frame around every screen. It owns layout only.

## Design

- `shell/navigation.ts` is the one navigation model. It feeds the rail, the
  bottom tab bar and the command palette, and no route is reachable only from
  the palette.
- **Rail.** 208 px wide by default. Between 1100 and 820 px it collapses to a 66
  px icon rail, and below 820 px it is replaced by a bottom tab bar.
- **Bottom bar.** Shows the active job (through job progress,
  [F4.4](../E4-shared-domain-components/F4.4-job-progress.md)), the worker
  state and held count, and the connection state.
- **Breadcrumbs.** A pure function from URL to `Crumb[]`. A crumb with no `href`
  is a grouping, not a link.
- **Page hero.** The shell's page header, which every route uses.
- **Routes.** The old paths, each lazy-loaded from `features/<screen>`: `/`,
  `/library`, `/library/{artists,genres,composers}[/:name]`, `/albums[/:id]`,
  `/searches`, `/playlists[/:id]`, `/errors`, `/inbox`, `/jobs[/:id]`,
  `/history`, `/apple`, `/maintenance` and `/settings[/annotations]`. Until a
  screen epic fills one, each shows its hero. `/` keeps the branded home from
  F2.7 until [F12.1](../E12-home-status-settings/F12.1-home-dashboard.md).
- **URL state.** `core/url-state.ts` wraps `linkedQueryParam` for `q`, `sort`,
  `offset`, `view` and `item`. Add `ngxtension` when this story needs it. The
  URL is authoritative for those values.

## S2.5.1 — Navigation model and breadcrumbs

**State:** New

**Acceptance:**

- `S2.5.1: every route in the model`: every route in `app.routes.ts` that has a
  page appears in the navigation model.
- `S2.5.1: breadcrumbs`: the old `breadcrumbs` spec cases, re-expressed, pass
  (for example `/library/artists/Björk` gives Library › Artists › Björk, and
  Library has no `href`).

## S2.5.2 — Rail, bottom bar and responsive layout

**State:** New

**Acceptance:**

- `S2.5.2: breakpoints`: at 1280, 1000 and 700 px the shell renders the full
  rail, the icon rail and the bottom tab bar, respectively.
- `S2.5.2: bottom bar job`: a running job in live state shows its progress in
  the bottom bar, and a held worker shows a Resume action that calls
  `POST /v1/jobs/worker/resume`.

## S2.5.3 — Command palette

**State:** New

**Acceptance:**

- `S2.5.3: opens and navigates`: ⌘K opens the palette, typing "inb" ranks Inbox
  first, and Enter navigates to it.
- The palette's entries come from the navigation model plus registered actions.
  It holds no list of its own.

## S2.5.4 — Routes and URL state

**State:** New

**Acceptance:**

- `S2.5.4: deep link`: loading `/library?q=genres:jazz&sort=year-` sets the URL
  state signals, and changing them updates the URL without a reload.
- Every route in the table loads its page, checked by one spec that walks the
  route config.
