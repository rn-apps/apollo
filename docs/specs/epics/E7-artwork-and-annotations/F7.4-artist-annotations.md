Facts about an artist that no file carries, stored in `apollo.db` per
[ADR-0010](../../../adr/ADR-0010.md) (for example whether a name is a band).
API: `GET /v1/annotations/artists/{name}`, `POST /v1/annotations/artists/{name}`
and `DELETE /v1/annotations/artist/{key}`. An artist rename in
[F6.5](../E6-tag-editing/F6.5-identity-editor.md) re-keys the annotation. The
open items from old apollo (`mb_artistid`, known-bands equivalence, rebuild
linkage tests) are settled when this feature is elaborated.
