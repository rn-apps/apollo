Facts about an album that no file carries, kept in `apollo.db` and keyed so they
survive a tag edit or an index rebuild. API: `GET /v1/annotations/albums/{key}`,
`POST /v1/annotations/albums/{key}` and `DELETE /v1/annotations/album/{key}`. It
shares the annotation store, re-key and merge logic with
[F7.4](F7.4-artist-annotations.md).
