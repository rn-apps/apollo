Editing one track's tags: prepare, validate, write atomically, update the index
and write an audit entry. API: `PATCH /v1/tracks/{id}` and
`GET /v1/tracks/{id}/check`. The UI is the E4 media editor with the library
adapter; this feature adds the backend workflow and that adapter only.
