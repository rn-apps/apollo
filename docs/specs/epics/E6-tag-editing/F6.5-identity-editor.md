Editing artist identity as main and featured artists rather than one free-text
string, following the plural vocabulary of [ADR-0016](../../../adr/ADR-0016.md).
It extends `PATCH /v1/tracks/{id}` and the bulk edit operations; renaming an
artist re-keys the artist annotation (see
[F7.4](../E7-artwork-and-annotations/F7.4-artist-annotations.md)). The control
is a field editor inside the E4 media editor and bulk edit panel.
