Applying one set of tag operations to many selected tracks, with the three bulk
states of [ADR-0012](../../../adr/ADR-0012.md). API: `POST /v1/tracks/bulk-edit`
(dry run, then apply as a `bulk_edit` job with one audit batch). The UI is the
E4 bulk edit panel through the E4 dry-run flow and job progress.
