Computing, for a selection, which tag values are shared, mixed or absent, so the
bulk panel can show them. API: `POST /v1/tracks/common-tags`, returning one
common-value record per field descriptor from `GET /v1/fields`. The inbox
version of this endpoint belongs to
[F8.2](../E8-inbox-and-intake/F8.2-staged-edits.md) and shares the same
computation.
