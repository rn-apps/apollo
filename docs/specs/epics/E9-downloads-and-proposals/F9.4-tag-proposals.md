Proposing tags for files from their path, from a filename pattern or from the
retained `.info.json`. API: `POST /v1/proposals`, returning per-file proposed
values with their source. The same proposals serve inbox files and library
tracks ([F11.4](../E11-checks-and-relocation/F11.4-update-tags-from-path.md)),
so the pattern parser lives once in the backend.
