Getting audio in with yt-dlp, a single URL or a whole playlist, and turning what
a file's path, filename or retained `.info.json` says into proposed tags that
the user accepts. At parity with old apollo; downloads land in the inbox
([E8](../E8-inbox-and-intake/index.md)) and run as jobs.
