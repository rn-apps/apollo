## Requirements for ngkit

- **Toolbar**: on `@angular/aria`'s toolbar pattern (roving focus), with start
  and end slots.
- **SelectionChip**: "N selected" with a clear action and a `cleared` output.
- **Tabs** (new): on `@angular/aria`'s tabs, with an optional link-driven mode
  so that the URL owns the active tab. The media editor uses tabs for Tags,
  Artwork, Trim and Checks.
