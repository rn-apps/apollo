## Requirements for ngkit

- **FieldControl**: a label, hint, error and a projected control, with the label
  and error wired to it for accessibility.
- **ChipsInput**: a multi-value text field shown as chips. Enter or a comma adds
  a value, Backspace on empty input removes the last, and paste splits on the
  separator. It can take suggestions from AutocompleteInput. It edits beets'
  plural fields ([ADR-0016](../../../adr/ADR-0016.md)).
- **AutocompleteInput**: a combobox on `@angular/aria`, with async suggestions,
  keyboard selection, and free text allowed.
- **Tri-state field** (new): wraps any control, with the states `untouched`,
  `mixed` (it shows the placeholder "Mixed" and the distinct values on hover)
  and `set`, plus an explicit "clear" action that yields `delete`. A blank
  input never means delete ([ADR-0012](../../../adr/ADR-0012.md)).
