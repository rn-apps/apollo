## Requirements for ngkit

- **Command registry**: commands with an id, label, group, keywords and a `run`
  handler, registered and unregistered by components as they mount.
- **Palette UI**: ⌘K or Ctrl-K, fuzzy ranking, grouped results, keyboard only,
  on `@angular/aria`'s combobox and listbox.
