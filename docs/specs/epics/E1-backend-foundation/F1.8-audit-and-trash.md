The machinery of [ADR-0009](../../../adr/ADR-0009.md) that every mutating
feature calls: an audit entry written before each change, a trash store, the
per-operation inverses, and batch undo. The history screen, pruning and empty
trash are [E14](../E14-audit-and-maintenance/index.md).

## Design

- `workflows/audit.py`: `AuditBatch` is an async context manager that yields a
  `batch_id`. `record(op, target, before, after, backup=None)` writes an
  `audit_entry` before the caller acts, and `complete(entry, result)` marks it
  done. A failed item marks its entry failed and does not abort the batch.
- `AuditOp`: `tag_write`, `file_move`, `file_replace`, `item_add`,
  `item_remove`, `inbox_promote`, `export`, `playlist_write`. Each has a
  registered inverse.
- `media/trash.py`: `put(path, batch_id) -> backup_path` moves a file into
  `trash/<batch_id>/`. Files are only ever moved there by
  `PathUtils.move_no_clobber`, never deleted.
- File writes go through `PathUtils.atomic_replace`. Moves use `move_no_clobber`
  and `prune_empty_parents`, and are kept inside the library root by
  `assert_within`.
- `undo(batch_id)` replays the batch's completed entries newest first. It writes
  an inverse entry, under a new batch, before each reversal.

## S1.8.1 — Audit batch and trash

**State:** New

**Acceptance:**

- `test_s1_8_1_1_entry_before_act`: when the act raises, its `audit_entry`
  exists with state `failed`, and the batch's other entries complete.
- `test_s1_8_1_2_trash_moves_never_deletes`: `put` moves the file into
  `trash/<batch_id>/`, and the source path no longer exists. An existing
  destination is never overwritten.
- `test_s1_8_1_3_outside_root_refused`: a move whose target is outside the
  library root raises before touching the disk.

## S1.8.2 — Undo a batch

**State:** New

**Acceptance:**

- `test_s1_8_2_1_tag_write_roundtrip`: undoing a `tag_write` batch on a fixture
  file restores its tags byte-for-byte in the tag frames, and the index.
- `test_s1_8_2_2_move_roundtrip`: undoing a `file_move` restores the old path
  and the index path, and prunes the emptied directories.
- `test_s1_8_2_3_undo_is_audited`: undo writes inverse entries under a new batch
  that references the original.
