`index/`: the single owner of beets ([ADR-0005](../../../adr/ADR-0005.md)), the
pure track projection ([ADR-0013](../../../adr/ADR-0013.md)), paging in beets
SQL, and the snapshot cache ([ADR-0006](../../../adr/ADR-0006.md)).

## Design

- `index/actor.py`: `LibraryActor = ThreadActor[Library]`. Its factory loads the
  generated beets config and registers apollo's media fields and flexible
  attributes (`apollo_filesize`, `apollo_file_missing`, `apollo_has_art`,
  `apollo_multidisc`). It is created in the lifespan and closed on shutdown.
- `index/dto.py`: `track_out(item)` builds a pydantic `TrackOut` from item
  fields and flexible attributes only.
- `index/paging.py`: `fetch_page(lib, query, sort, offset, limit)` returns
  `(items, total)` through beets' own parser and `WHERE` clause, with
  `LIMIT/OFFSET`. It returns `None` when the query or sort uses a flexible
  attribute, a slow sort or an album join, and the caller then falls back to
  `Library.items()`.
- `index/paging.py` also owns the page token of beets lists.
  `encode_page_token(offset, query, sort)` and
  `decode_page_token(raw, query, sort)` use URL-safe base64 over compact JSON.
  A malformed token, or one issued for another query or sort, raises the kit's
  `InvalidCursor` (400). `beets_page_params(cap=500, default=100)` is the
  routes' dependency: it reads `pageSize` through the kit's `clamp_page_size`
  and decodes `pageToken`.
- `index/snapshot.py`: `Snapshot[T]`, with `get()` (lazy and coalesced) and
  `invalidate()`. A registry lists every snapshot, and `invalidate_all()` is
  called on mutation.

## S1.5.1 — Library actor

## S1.5.2 — Pure track projection

**State:** New

**Acceptance:**

- `test_s1_5_2_1_projection_no_syscalls`: building a `TrackOut` with `os.stat`,
  `open` and `subprocess` patched to raise succeeds.

  ([ADR-0016](../../../adr/ADR-0016.md)), and `hasArtwork`, never artwork
  bytes.

## S1.5.3 — Paging in beets SQL

**State:** New

**Acceptance:**

- `test_s1_5_3_1_equivalence`: over the fixture library and a table of queries
  and sorts, `fetch_page` returns the same items in the same order as slicing
  `Library.items()`, and the right `total`.
- `test_s1_5_3_2_declines_flexible`: a query or sort on an `apollo_*` attribute
  returns `None`.
- `test_s1_5_3_3_token_round_trip`: a token decodes to the offset it was issued
  for, under the same query and sort.
- `test_s1_5_3_4_token_rejected`: a malformed token, or one presented with
  another query or sort, answers the kit's 400 problem.
