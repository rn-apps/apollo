# S1.2.1 — Settings and runtime tree

Brief for
[S1.2.1](../F1.2-settings-and-runtime.md#s121-settings-and-runtime-tree), at
`cb2ba14` plus the commit that adds this brief.

## Goal

Add `apollo_api.platform`: an `APOLLO_*` settings class, and a `prepare` step
that creates the `.apollo/` runtime tree and writes the generated beets
configuration. Ported from the old
`rn_backup/apollo/apps/api/src/apollo/config.py`, behaviour not layout.

## Settled

- `platform` is layer 1 of the backend
  ([backend architecture](../../../../architecture/backend.md)): no music
  knowledge beyond the beets config it writes, and no imports from other
  `apollo_api` packages.
- Two modules, as F1.2 says: `platform/settings.py` holds the `Settings` class,
  its path properties and `get_settings()`; `platform/runtime.py` holds the
  runtime tree, the beets config payload and `prepare()`.
- `APOLLO_JOBS_AUTOSTART` is not carried
  ([ADR-0007](../../../../adr/ADR-0007.md)).
- The beets config payload is the old `beets_config_payload`, verbatim,
  including `per_disc_numbering: true`, the `paths` block and
  `musicbrainz.enabled: false`.
- YAML is written with `rn_forge.commons.YamlUtils.write_file` (commons already
  depends on `ruamel.yaml`). Do not import `yaml` (PyYAML) directly: it has no
  type stubs, and pyright runs in strict mode.
- The library root is never created: a typo in `APOLLO_LIBRARY_ROOT` must stay
  visible.
- `prepare()` is not called at startup in this story; S1.2.2 wires the lifespan.

## Current behaviour

- `apps/api/src/apollo_api/` holds `__init__.py`, `app.py`, `errors.py`,
  `routes.py` and `py.typed`. There is no `platform` package.
- `pydantic-settings` (2.16.x) is installed since S1.1.1.
- With the tests below written and nothing else changed, collection fails with
  `ModuleNotFoundError: No module named 'apollo_api.platform'` (the test
  module imports it at the top).

## Change

1. `apps/api/src/apollo_api/platform/__init__.py`: a one-line module docstring
   ("Process-wide plumbing: settings, the runtime tree and, later, the
   database, jobs and logging."). No re-exports.

1. `apps/api/src/apollo_api/platform/settings.py`:

    - `class Settings(BaseSettings)` with
      `model_config = SettingsConfigDict(env_prefix="APOLLO_", env_file=".env", extra="ignore")`
      and these fields:

        | Field | Type | Default |
        | -- | -- | -- |
        | `state_dir` | `Path` | `Path(".apollo")` |
        | `library_root` | `Path` | `Path.home() / "Music" / "Library"` (a `default_factory`) |
        | `music_xml_path` | `Path \| None` | `None` |
        | `default_page_size` | `int` | `100` |
        | `bind_host` | `str` | `"127.0.0.1"` |
        | `apple_relocation_verified` | `bool` | `False` |
        | `job_history_limit` | `int` | `500` |

    - Read-only properties, each relative to `state_dir`: `config_path`
      (`config/config.yaml`), `beets_db_path` (`db/library.db`),
      `apollo_db_path` (`db/apollo.db`), `backups_path` (`db/backups`),
      `logs_path` (`logs`), `inbox_path` (`inbox`), `trash_path` (`trash`),
      `cache_path` (`cache`), `work_path` (`work`), `reports_path` (`reports`).

    - `get_settings() -> Settings`, decorated with `functools.lru_cache`,
      returning `Settings()`.

    - A class docstring stating that `state_dir` is disposable state and
      `library_root` is the user's library, never created implicitly.

1. `apps/api/src/apollo_api/platform/runtime.py`:

    - `def runtime_dirs(settings: Settings) -> tuple[Path, ...]`: `state_dir`,
      then the parents of `config_path` and `beets_db_path`, then
      `backups_path`, `logs_path`, `inbox_path`, `trash_path`, `cache_path`,
      `work_path`, `reports_path`.

    - `def beets_config(settings: Settings) -> dict[str, Any]`: returns exactly
      this payload, where `PARENT = "%first{$genres}/$albumartist/$album"` and
      `TEMPLATE = f"{PARENT}/$title"` are module constants (keep the old
      comments that explain `%first` and why `singleton` and `comp` repeat
      `default`):

        ```python
        {
            "directory": str(settings.library_root.expanduser().resolve()),
            "library": str(settings.beets_db_path.expanduser().resolve()),
            "id3v23": False,
            "per_disc_numbering": True,
            "threaded": False,
            "timid": True,
            "quiet_fallback": "skip",
            "import": {
                "copy": False,
                "move": False,
                "write": False,
                "autotag": False,
                "incremental": True,
                "resume": False,
                "duplicate_action": "skip",
            },
            "asciify_paths": True,
            "replace": {
                "[\\\\/]": "_",
                "[:]": "_",
                "[\\x00-\\x1f]": "",
                "^\\.": "_",
                "^\\s+": "",
                "\\s+$": "",
            },
            "paths": {
                "apollo_multidisc:1": f"{PARENT}/Disc $disc/$title",
                "default": TEMPLATE,
                "singleton": TEMPLATE,
                "comp": TEMPLATE,
            },
            "plugins": [],
            "musicbrainz": {"enabled": False, "searchlimit": 5},
        }
        ```

    - `def prepare(settings: Settings) -> None`:
      `mkdir(parents=True, exist_ok=True)` on every path from `runtime_dirs`
      (after `expanduser().resolve()`), then
      `YamlUtils.write_file(beets_config(settings), settings.config_path.expanduser().resolve())`.
      Docstring says the library root is deliberately not created.

## Tests first

Create `apps/api/tests/test_s1_2_1_settings.py`. Import `Settings` from
`apollo_api.platform.settings` and `prepare`, `beets_config` from
`apollo_api.platform.runtime` at the top. Every test builds settings with
`_env_file=None` unless it is testing `.env`, and first removes every `APOLLO_*`
variable from the environment with `monkeypatch.delenv(..., raising=False)`
(write a small fixture that does this for all seven names).

- `test_s1_2_1_1_defaults`: `Settings(_env_file=None)` has every default in the
  table above; `library_root == Path.home() / "Music" / "Library"`;
  `music_xml_path is None`; it has no `jobs_autostart` attribute.
- `test_s1_2_1_2_env_overrides`: write `tmp_path / ".env"` with
  `APOLLO_DEFAULT_PAGE_SIZE=10` and `APOLLO_JOB_HISTORY_LIMIT=7`; set
  `APOLLO_DEFAULT_PAGE_SIZE=25`, `APOLLO_BIND_HOST=0.0.0.0` and
  `APOLLO_APPLE_RELOCATION_VERIFIED=true` with `monkeypatch.setenv`; build
  `Settings(_env_file=tmp_path / ".env")`. Assert `default_page_size == 25`
  (the environment beats `.env`), `job_history_limit == 7`,
  `bind_host == "0.0.0.0"`, `apple_relocation_verified is True`.
- `test_s1_2_1_3_prepare_creates_tree`: settings with
  `state_dir=tmp_path / "state"` and `library_root=tmp_path / "library"`.
  After `prepare`, each of `config`, `db`, `db/backups`, `logs`, `inbox`,
  `trash`, `cache`, `work`, `reports` is a directory under the state dir, and
  `config/config.yaml` exists. `tmp_path / "library"` does not exist. Record
  every path under the state dir with its file bytes, run `prepare` again, and
  assert the record is equal.
- `test_s1_2_1_4_beets_config`: same settings; after `prepare`, read
  `config/config.yaml` with `YamlUtils.read_file` and assert it equals
  `beets_config(settings)`. Then assert, on the read value: `id3v23 is False`,
  `per_disc_numbering is True`, `threaded is False`, `timid is True`; `import`
  has `copy`, `move`, `write`, `autotag` all `False`, `incremental is True`,
  `duplicate_action == "skip"`; `asciify_paths is True`; `replace` equals the
  six-entry map above; `directory == str((tmp_path / "library").resolve())`;
  `library == str((tmp_path / "state" / "db" / "library.db").resolve())`;
  `paths["default"] == "%first{$genres}/$albumartist/$album/$title"`.

If `YamlUtils.read_file` returns ruamel container types that do not compare
equal to plain `dict`, convert with `json.loads(json.dumps(...))` before the
equality assert and record it in `## Result`.
