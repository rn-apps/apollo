# S1.1.3 — CI has ffmpeg and ffprobe

Brief for
[S1.1.3](../F1.1-dependencies-and-entry.md#s113-ci-has-ffmpeg-and-ffprobe), at
`cb2ba14` plus the commit that adds this brief.

## Goal

Every CI job that uses the generated setup action gets `ffmpeg` and `ffprobe`,
through a repo-owned composite action that kiln wires in as a setup hook.

## Settled

- CI runs on `ubuntu-latest` (`.github/workflows/ci.yml`). `ffmpeg` comes from
  apt; the Debian/Ubuntu `ffmpeg` package also installs `ffprobe`.
- `.github/actions/setup/action.yml` and every workflow are kiln-generated. The
  hook is declared in `.rn-forge/kiln/config.toml` and rendered by
  `task kiln:apply`; no generated file is edited by hand.
- The second acceptance bullet (a PR run shows `ffprobe -version`) is checked by
  the owner after a push. This story is built and validated locally only.

## Current behaviour

- `.rn-forge/kiln/config.toml` has `[ci.hooks]` with `setup = []` and
  `docs = []`.
- `.github/actions/` holds only `setup/`. Its `action.yml` ends with the
  `actions/setup-node` step and runs no hook.
- No test covers this; the evidence is `kiln doctor`'s `ci-hooks` check (it
  fails when a listed hook directory has no `action.yml`) and the rendered
  setup action.

## Change

1. Create `.github/actions/media-tools/action.yml` with exactly:

    ```yaml
    name: Install media tools
    description: >-
      Install ffmpeg and ffprobe, which apollo's media tests call. Run by the
      generated setup action as a [ci.hooks] setup step.

    runs:
      using: composite
      steps:
        - name: Install ffmpeg
          shell: bash
          run: |
            sudo apt-get update
            sudo apt-get install --yes --no-install-recommends ffmpeg

        - name: Show ffprobe version
          shell: bash
          run: ffprobe -version
    ```

1. `.rn-forge/kiln/config.toml`, under `[ci.hooks]`: change `setup = []` to
   `setup = ["./.github/actions/media-tools"]`. Change nothing else.

1. Run `task kiln:apply`. Expect it to re-render
   `.github/actions/setup/action.yml` (a final step
   `uses: ./.github/actions/media-tools`), and possibly `.github/dependabot.yml`
   and `.rn-forge/kiln/state.json`. Record every file it changed in
   `## Result`. If it changes any file other than these, stop and report.

## Tests first

None: this story adds no Python or TypeScript code. Before the change, confirm
the rendered setup action has no `media-tools` step. After it, confirm:

- `.github/actions/setup/action.yml` ends with a step
  `uses: ./.github/actions/media-tools`;
- `task validate` passes, which runs `kiln doctor` (including `ci-hooks`),
  `actionlint` and `zizmor` over the new action.

## Out of scope

- Installing ffmpeg locally or on macOS; using ffmpeg from Python (later
  `media/` stories).
- Pushing, opening a PR or editing any workflow by hand.
