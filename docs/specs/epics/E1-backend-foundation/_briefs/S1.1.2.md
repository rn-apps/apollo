# S1.1.2 — `apollo-api serve` runs the app

Brief for
[S1.1.2](../F1.1-dependencies-and-entry.md#s112-apollo-api-serve-runs-the-app),
at `1639856` plus the commit that adds this brief.

## Goal

Replace the broken seeded console script with `apollo_api.cli:main`, an
`rn_forge.cli.CliApp` whose one command, `serve`, runs the API under uvicorn on
`APOLLO_BIND_HOST` and port 8000.

## Settled

- The host comes from `Settings.bind_host` (`apollo_api.platform.settings`,
  added by S1.2.1); the port is the constant `8000`, as `task api:dev` uses.
- `main` is the `CliApp` instance itself; `CliApp.__call__` returns the exit
  code, so `[project.scripts]` needs no wrapper function.
- `apollo_api` may not import `typer` or `click` (`.importlinter`,
  `frameworks-come-from-rn-forge`). Register the command with
  `@main.command()`; never import typer.
- uvicorn is a runtime dependency since S1.1.1.
- `task api:dev` keeps running uvicorn with `--reload` directly; it is not
  changed.

## Current behaviour

- `apps/api/pyproject.toml` has
  `[project.scripts] apollo-api = "apollo_api:main"`. `apollo_api/__init__.py`
  defines no `main`, so the script fails with `ImportError` when run.
- There is no `apollo_api/cli.py`.
- With the tests below written and nothing else changed, collection fails with
  `ModuleNotFoundError: No module named 'apollo_api.cli'`.

## Change

1. Create `apps/api/src/apollo_api/cli.py`:

    - `PORT = 8000` and `APP = "apollo_api.app:app"` module constants.
    - `main = CliApp("apollo-api", "Run the apollo API.")` (from `rn_forge.cli`).
    - `def uvicorn_config(settings: Settings) -> uvicorn.Config`: returns
      `uvicorn.Config(APP, host=settings.bind_host, port=PORT)`.
    - `@main.command()` `def serve() -> None`: docstring "Serve the API on
      APOLLO_BIND_HOST, port 8000."; body
      `uvicorn.Server(uvicorn_config(get_settings())).run()`.
    - A module docstring.

1. `apps/api/pyproject.toml`:
   `[project.scripts] apollo-api = "apollo_api.cli:main"`. Change nothing else
   in the file.

1. Run `task setup` so the installed script points at the new entry.

## Tests first

Create `apps/api/tests/test_s1_1_2_cli.py`. Import `main` and `uvicorn_config`
from `apollo_api.cli`, `Settings` and `get_settings` from
`apollo_api.platform.settings`, at the top. Use a fixture that removes
`APOLLO_BIND_HOST` from the environment and calls `get_settings.cache_clear()`
before and after each test.

- `test_s1_1_2_1_serve_builds_uvicorn_config`:
  `uvicorn_config(Settings(_env_file=None, bind_host="0.0.0.0"))` has
  `host == "0.0.0.0"`, `port == 8000` and `app == "apollo_api.app:app"`. Then
  set `APOLLO_BIND_HOST=127.0.0.2`, replace `uvicorn.Server.run` with
  `monkeypatch.setattr` by a function that records `self.config` and returns
  `None`, and call `main.run(["serve"])`. Assert it returns `0`, that exactly
  one config was recorded, and that its `host == "127.0.0.2"` and
  `port == 8000`. No socket is bound.
