# S1.9.1 — Fixtures and the library-mutation guard

Brief for
[S1.9.1](../F1.9-harness-and-guardrails.md#s191-fixtures-and-the-library-mutation-guard),
at `cb2a13b` plus the commit that adds this brief.

## Goal

Give every backend test a temporary state directory and library by default, a
`fixture_library` builder that writes small tagged audio files, and a guard that
fails any unmarked test that points `APOLLO_LIBRARY_ROOT` outside its
`tmp_path`. Ported from the old `rn_backup/apollo/apps/api/tests/conftest.py`.

## Settled

- Audio comes from `ffmpeg` (0.2 s sine, `mp3`, `m4a`, `flac`), generated once
  per session, as in the old conftest. Tags are written with
  `ffmpeg -metadata` and read back with `ffprobe`, both through
  `rn_forge.commons.Process.execute`. No Python tag library is used:
  `mediafile` ships no type stubs and pyright is strict over the tests.
  `ffmpeg` and `ffprobe` are on the developer's PATH (Homebrew) and in CI
  (S1.1.3).
- The guard is a **function-scoped** autouse fixture, not session-scoped as the
  acceptance says: it needs each test's markers and `tmp_path`. Record this as
  a deviation; the reviewer updates the acceptance.
- The guard's rule: at teardown, unless the test is marked `library_mutation`,
  fail when `APOLLO_LIBRARY_ROOT` is set and does not resolve inside the
  test's `tmp_path`. An unset variable is allowed (tests of the settings
  defaults delete it and touch no disk).
- `library_mutation` is registered in `conftest.py` (`pytest_configure`), and
  `apps/api/pyproject.toml` `addopts` deselects it, so `task test` never runs
  such a test.
- The path tree follows S1.2.1's template:
  `<genre>/<albumartist>/<album>/<title>.<ext>`.
- `app_client` from F1.9's design is not in this story; it arrives with the
  first story that needs a client with its lifespan run.

## Current behaviour

- `apps/api/tests/` has no `conftest.py`. Tests that need a state dir set
  `APOLLO_STATE_DIR`/`APOLLO_LIBRARY_ROOT` themselves
  (`test_s1_2_2_logging.py`) or delete them (`test_s1_2_1_settings.py`).
- `apps/api/pyproject.toml` `[tool.pytest.ini_options]` has
  `addopts = "-ra --import-mode=importlib"`.
- With the tests below written and nothing else changed, both fail at setup with
  `fixture 'fixture_library' not found` and `fixture 'pytester' not found`.

## Change

1. Create `apps/api/tests/conftest.py`:

    - `pytest_plugins = ["pytester"]`.
    - `def pytest_configure(config: pytest.Config) -> None`: registers
      `library_mutation: touches a library outside tmp_path; run only by the acceptance procedure`.
    - `class TrackSpec(TypedDict, total=False)` with `title: Required[str]`,
      `artist: Required[str]`, `album: Required[str]`, `genre: Required[str]`,
      `albumartist: str` (defaults to `artist`), `track: int` (defaults to 1),
      `ext: str` (`"mp3"`, `"m4a"` or `"flac"`; defaults to `"mp3"`).
    - Session fixture `audio_fixtures(tmp_path_factory) -> Path`: the old
      fixture, unchanged in behaviour
      (`Process.execute("fixture-<name>", "ffmpeg", "-hide_banner", "-loglevel", "error", "-f", "lavfi", "-i", "sine=frequency=440:duration=0.2", *codec, str(root / name))`
      with the old three codecs).
    - Autouse fixture
      `configured_env(tmp_path, monkeypatch, request) -> Iterator[dict[str, Path]]`:
      sets `APOLLO_STATE_DIR` to `tmp_path / ".apollo"` and
      `APOLLO_LIBRARY_ROOT` to `tmp_path / "library"`, calls
      `get_settings.cache_clear()`, yields `{"state": ..., "library": ...}`,
      then calls `get_settings.cache_clear()` and applies the guard rule above
      with
      `pytest.fail(f"APOLLO_LIBRARY_ROOT={value} is outside tmp_path; mark the test library_mutation", pytrace=False)`.
    - Fixture
      `fixture_library(audio_fixtures, configured_env) -> Callable[[Sequence[TrackSpec]], Path]`:
      the returned function writes each track to
      `library / genre / albumartist / album / f"{title}.{ext}"` (parents
      created) with `ffmpeg -hide_banner -loglevel error -i <base file> -c copy`
      and `-metadata` for `title`, `artist`, `album_artist`, `album`,
      `genre`, `track`, then returns the library root.
    - Helper `probe_tags(path: Path) -> dict[str, str]`, a plain function used by
      the tests: runs `ffprobe -v error -show_entries format_tags -of json` and
      returns the `format.tags` map with lower-cased keys (FLAC reports Vorbis
      keys in upper case).

1. `apps/api/pyproject.toml`:
   `addopts = "-ra --import-mode=importlib -m 'not library_mutation'"`. Change
   nothing else.

## Tests first

Create `apps/api/tests/test_s1_9_1_harness.py`. `conftest.py` cannot be imported
under `--import-mode=importlib`, so the conftest also exposes a fixture
`probe_tags_fn` that returns `probe_tags`; the tests use that.

- `test_s1_9_1_1_fixture_library`: build a spec of three tracks: one `mp3`
  (`Jazz` / `Miles Davis` / `Kind of Blue` / `So What`, track 1), one `m4a` in
  the same album (track 2, `Freddie Freeloader`), one `flac` (`Electronic` /
  `Björk` / `Post` / `Army of Me`). Assert each file exists at
  `<library>/<genre>/<albumartist>/<album>/<title>.<ext>`, the library root is
  `configured_env["library"]`, and each file's probed tags have the spec's
  `title`, `artist`, `album`, `genre`, and a `track` that starts with the
  spec's number (formats differ: `1`, `1/0`).
- `test_s1_9_1_2_guard`: with `pytester`, copy this directory's `conftest.py`
  (`pytester.makeconftest(Path(__file__).with_name("conftest.py").read_text())`)
  and make a test file with three tests: one that does nothing; one that
  sets `APOLLO_LIBRARY_ROOT` to a path outside its `tmp_path` with
  `monkeypatch.setenv`; and the same marked `library_mutation`. Run
  `pytester.runpytest("-p", "no:cacheprovider")`. Assert
  `assert_outcomes(passed=3, errors=1)` (the unmarked override passes its body
  and errors at teardown) and that the output matches
  `*outside tmp_path; mark the test library_mutation*`.

## Rules

- Use `task` for the toolchain. Never call `uv`, `pytest`, `ruff`, `pyright` or
  `kiln` directly. Tests may call `ffmpeg`/`ffprobe` through
  `Process.execute`.
- pyright is strict over `tests/` too; ruff's docstring and annotation rules are
  relaxed there.
- Tests are named `test_s1_9_1_<n>_<slug>` and live in `apps/api/tests/`.
- Add no dependency. Edit no kiln-generated file. Do not commit or push.
