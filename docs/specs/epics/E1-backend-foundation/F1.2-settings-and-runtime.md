`platform/settings.py` and `platform/runtime.py`: the `APOLLO_*` settings, the
`.apollo/` runtime tree, the generated beets config, and logging.

## Design

| Setting | Default | Notes |
| -- | -- | -- |
| `APOLLO_STATE_DIR` | `.apollo` | the root of the runtime tree |
| `APOLLO_LIBRARY_ROOT` | `~/Music/Library` | not editable at runtime |
| `APOLLO_MUSIC_XML_PATH` | unset | overrides the AppleScript XML export |
| `APOLLO_DEFAULT_PAGE_SIZE` | 100 |  |
| `APOLLO_BIND_HOST` | `127.0.0.1` |  |
| `APOLLO_APPLE_RELOCATION_VERIFIED` | `false` | gates Music.app location updates |
| `APOLLO_JOB_HISTORY_LIMIT` | 500 |  |

`APOLLO_JOBS_AUTOSTART` is not carried ([ADR-0007](../../../adr/ADR-0007.md)).
The runtime tree under the state directory is `config/`, `db/` (with
`backups/`), `logs/`, `inbox/`, `trash/`, `cache/`, `work/` and `reports/`.

## S1.2.1 — Settings and runtime tree

**State:** New

**Acceptance:**

- `test_s1_2_1_1_defaults`: every default in the table holds, with no
  environment set.
- `test_s1_2_1_2_env_overrides`: `APOLLO_*` variables and `.env` override the
  defaults.
- `test_s1_2_1_3_prepare_creates_tree`: preparing the settings creates every
  runtime directory under a `tmp_path` state directory, and running it again
  changes nothing.
- `test_s1_2_1_4_beets_config`: the generated beets config has `id3v23: no`,
  `per_disc_numbering`, `threaded: no`, `timid`, import copy, move, write and
  autotag all off, `incremental`, `duplicate_action: skip`, `asciify_paths`,
  and the old replace map, as in the old `beets_config_payload`.

## S1.2.2 — Logging to the runtime tree

**State:** New

**Acceptance:**

- `AppLogger.initialize` runs once in the lifespan, with root logger `apollo`
  and a rotating file under `logs/`.
- `test_s1_2_2_1_log_file_written`: a startup in a `tmp_path` state directory
  writes the log file.
- `AppConfig(log=log_server_errors())` sends 5xx tracebacks to that file.
