The async engine, sessions, models and the baseline migration of
[ADR-0021](../../../adr/ADR-0021.md).

## Design

`platform/db.py` provides the engine, from `create_sqlite_engine`, and an
`async_sessionmaker(expire_on_commit=False)`. It also provides the FastAPI
dependency, `Session = Annotated[AsyncSession, Depends(session)]`.

Models (`platform/models.py` for `job`, `job_log`, `audit_entry` and `setting`;
the domain tables beside their workflows) all derive from the kit's `Base`. The
baseline creates `job`, `job_log`, `audit_entry`, `setting`, `playlist`,
`playlist_track`, `artist_annotation`, `album_annotation`, `track_check` and
`apple_stat`, with the old columns and no `saved_search`. Migrations live in
`apollo_api/migrations/`.
