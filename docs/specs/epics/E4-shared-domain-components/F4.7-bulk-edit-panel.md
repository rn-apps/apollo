Edit many items at once. It is a side panel, like the media editor, whose fields
are tri-state (F3.2): `untouched`, `mixed` or `set`, plus an explicit `delete`
([ADR-0012](../../../adr/ADR-0012.md)). It loads common values through a
`BulkAdapter.common(targets)`, and compiles the touched fields into the
operations list for `BulkAdapter.apply(targets, operations, dryRun)`. It saves
through the dry-run flow. Library selections and inbox selections use the same
panel, with different adapters.

## S4.7.1 — Three states compile to operations

**State:** New

**Acceptance:**

- `S4.7.1: compile`: with `genres` set, `year` untouched and `comments` deleted,
  the operations are `set genres` and `delete comments` only.
- `S4.7.1: blank never clears`: emptying a mixed field leaves it `untouched`.
- `S4.7.1: dry run`: Save previews through F4.3 with a per-item diff.
