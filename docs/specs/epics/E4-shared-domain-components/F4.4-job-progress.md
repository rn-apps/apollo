One rendering of a job: its type label, state badge and progress bar, a message,
and a cancel action. It has `full`, `row` and `compact` variants. It reads live
state ([ADR-0008](../../../adr/ADR-0008.md)) and never polls.

## S4.4.1 — Job progress variants

**State:** New

**Acceptance:**

- `S4.4.1: live update`: a `job` frame that changes progress updates the bar
  with no fetch.
- `S4.4.1: terminal`: a terminal frame shows the end state and its message, and
  the cancel action disappears.
- `S4.4.1: one rendering`: the `compact` variant is what the bottom bar uses. No
  other component renders a job's progress (one grep in the spec).
