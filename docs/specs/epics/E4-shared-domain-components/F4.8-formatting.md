One set of pure pipes and functions in `core/format/`:

- `duration` (`m:ss` and `h:mm:ss`), and a precise `time` (`m:ss.cc`) for trim;
- `bytes` (KB/MB/GB, base 1024);
- `quality` (codec, bitrate, sample rate, from the probe);
- `relative` (time ago);
- `problemMessage`, which reads a problem's `detail` and falls back to its
  title.
