Show, set from a file, set from a URL, or clear the artwork of a track, an album
or an inbox file, through an `ArtworkAdapter`: `get(target) → url | null`,
`put(target, file | url)`, `clear(target)`. Images always load from the artwork
endpoint ([ADR-0011](../../../adr/ADR-0011.md)), never inline. Setting from a
URL is disabled when `artwork_url` is unavailable (iCloud Sync Library).

## S4.5.1 — One picker for three targets

**State:** New

**Acceptance:**

- `S4.5.1: three targets`: the same picker sets artwork on fake track, album and
  inbox targets.
- `S4.5.1: url disabled`: with `artwork_url` unavailable, the URL field is
  disabled, with its reason.
- `S4.5.1: thumbnail`: list cells use the endpoint's thumbnail size, with the
  ETag left to the browser cache.
