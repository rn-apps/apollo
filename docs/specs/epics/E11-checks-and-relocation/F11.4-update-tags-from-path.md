Fixing a track whose tags disagree with its path by taking the tags from the
path, the reverse of relocation. It uses `POST /v1/proposals` with the path
source and `POST /v1/proposals/accept` from
[E9](../E9-downloads-and-proposals/index.md), through the E4 dry-run flow, with
no modal of its own on the errors page.
