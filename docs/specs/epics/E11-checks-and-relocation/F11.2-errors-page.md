The list of tracks that fail a check, grouped by rule, with a summary. API:
`GET /v1/errors` and `GET /v1/errors/summary`. The page is the E4 track
workspace with the errors column set, selection toolbar and the shared media
editor, with no private paging, selection or edit dialog.
