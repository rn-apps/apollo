Running the tag and path checks over every track and caching the results in
`apollo.db` so the errors page and the grid badges read them without
recomputing. API: `GET /v1/tracks/{id}/check` reads the cache entry. A `check`
job fills and refreshes the cache. The check engine is shared with the inbox
gates in [F8.3](../E8-inbox-and-intake/F8.3-tag-check-gates.md).
